# Exercises: Research Habits That Compound

## Exercise 1: Write Your First CLAUDE.md (15 min)

Navigate to a real research project directory — your dissertation folder, a data analysis project, anything active.

Ask CC:

> "Look at the files in this directory. Write a CLAUDE.md for this project. Include: the research purpose in one sentence, the file structure with a note on what each folder and key file does, the current status of the project, and any conventions I should know about."

Review what CC produces carefully. Add anything it missed — conventions it could not infer, context that only you know, the "do not" items that protect fragile files. Remove anything inaccurate.

Now start a completely new CC session in that directory. Without giving CC any additional context, ask:

> "Based on CLAUDE.md, what would be a good task to work on first?"

Observe whether CC gives you a grounded, specific suggestion or a generic one. If the suggestion is generic, look at your CLAUDE.md — the current-status section is probably missing or vague. Add it and try again.

The goal: a CLAUDE.md where a cold session immediately produces useful, specific task suggestions.

## Exercise 2: The Week-in-Review Update (10 min)

At the end of any work session — today's session counts — ask CC:

> "Summarize what we accomplished in this session in three bullet points."

Then ask:

> "Append those bullet points to CLAUDE.md under a section called 'Session Log' with today's date."

Start a new session the next day. Ask:

> "Read CLAUDE.md. What is the context for today's work and what would you suggest I pick up?"

Compare the quality of this session start to how you used to start sessions before this chapter. The difference is the return on those 60 seconds of update work.

---

## Exercise 3: The Compound Habit (5 min reflection)

There is no CC prompt for this exercise. Close your terminal and think.

Write down answers to these three questions — in a notebook, a text file, anywhere that is not ephemeral:

1. **What three things would CC need to know to be immediately useful in your current project?** These are your first CLAUDE.md sections.

2. **What is one repetitive task in your research workflow that CC could handle if it had that context?** This is the payoff — the thing you will stop doing manually.

3. **What is one habit from this tutorial that you will start using this week?** Not eventually. This week.

There is no answer to review here. The answer lives in how you work next week. But researchers who write down specific intentions act on them at twice the rate of those who do not.
